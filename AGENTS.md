# Правила для ревьюеров

MCP-сервер Контур.Эльбы: один модуль `elba_mcp.py` — и пакет PyPI (`uvx elba-mcp`, `pyproject.toml`),
и самостоятельный скрипт PEP 723 (`uv run --script elba_mcp.py`). Через него выставляются настоящие счета,
акты и УПД клиентам — ошибка стоит денег и репутации. Проект публичный.

## На что смотреть в первую очередь

- Деньги: сумма, количество, НДС, номер и дата документа, контрагент. Любая подстановка значения
  по умолчанию, которая может молча дать не тот документ, — серьёзное замечание.
- Дубли: повторный вызов не должен тихо создавать второго контрагента или второй счёт там, где
  пользователь этого не ждёт.
- Журнал счетов (`~/.local/state/elba-mcp/journal-<org>.json`): API не отдаёт список счетов, поэтому журнал —
  единственный источник «кто не оплатил». Сбой журнала не должен скрыть id созданного документа. Сервер
  запущен в каждой сессии: запись в журнал — под `flock`, а проверка дубля + создание + запись и опрос
  ленты оплат — под общей блокировкой операции.
- Ошибки API: HTTP-ошибка и неожиданный ответ должны дойти до пользователя текстом, а не превратиться
  в пустой результат или «успех».
- Секреты: ключ `ELBA_API_KEY` только из окружения или `.env`, никогда в коде, логах, тексте ошибок.
- Личные данные: в коде, README, тестах и примерах не должно быть ИНН, id организаций и банковских счетов,
  данных клиентов, путей и имён с машины автора.
- Пакет: в wheel — только `elba_mcp.py`; версия — `__version__` в модуле, `pyproject.toml` читает её оттуда.
  Метаданные скрипта (`# /// script`) и `pyproject.toml` должны требовать одно и то же.

## Соглашения

- HTTP — только stdlib `urllib`, зависимость одна: `mcp>=2.3,<3` (класс `MCPServer`).
- README, докстринги и тексты ошибок — на русском: Эльба — русский сервис (решение владельца
  26.10.2026). Английский перевод не замечание. LICENSE — стандартный текст MIT.
- Минимум кода, без абстракций под будущее.
- Тесты — `tests/test_server.py` на моке API (класс `Fake`), запуск `uv run pytest -q`; новое поведение и
  исправленный баг — с тестом.

## Известное

- Windows: нет `fcntl` — операции с журналом отказывают (сознательно, иначе дубли).
- Не покрыты: товары, накладные, изменение и удаление ссылки, пагинация, плейсхолдеры шаблонов.
- Создание акта и УПД и ссылка на УПД через `document-links` на живом API не проверены.

API: https://developer.kontur.ru/doc/elba.public.api, спецификация — https://elba-api.kontur.ru/swagger/v1/swagger.json
